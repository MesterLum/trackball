# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, assume good intent, give and accept constructive
feedback, and focus on what is best for the people building and using these trackballs.
Harassment, insults and personal attacks are not tolerated.

## Reporting

If you experience or witness unacceptable behaviour, contact the maintainer privately
through GitHub ([@MesterLum](https://github.com/MesterLum)). Reports are handled
confidentially. The maintainer may remove comments, issues or contributions that break this
code, and may block repeat offenders.
